# Real Zoro — Site v14

Site multipágina otimizado para GitHub Pages e preparado para futura hospedagem na DISCloud.

## Estrutura
- `index.html` — Real Zoro
- `limpador-pro/index.html` — Limpador Pro
- `zpack/index.html` — ZPack
- `assets/` — CSS, JavaScript, imagens e mídias

## Novidades da v14
- Nova área de resultados reais no ZPack com destaque para Venas.
- Feedbacks organizados por pessoa, ganho de FPS e configuração.
- Recomendação em vídeo de Pouca Mira.
- Vídeos com `preload="none"` e imagens de prova convertidas para WebP.
- Fluxo simples de contratação no ZPack e de compra/ativação no Limpador Pro.
- Atalho discreto na Home para os resultados do ZPack.
- Ícones dos destaques da v1.0.2 padronizados em SVG monocromático.
- Ajustes responsivos específicos para a nova área de prova social.

## Publicação
Extraia o ZIP e envie os arquivos e pastas preservando esta estrutura. Não envie o ZIP como um único arquivo para o repositório.
