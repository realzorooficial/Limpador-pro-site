# Real Zoro — Site v15

Site multipágina otimizado para GitHub Pages e preparado para futura hospedagem na DISCloud.

## Estrutura
- `index.html` — Real Zoro
- `limpador-pro/index.html` — Limpador Pro
- `zpack/index.html` — ZPack
- `assets/` — CSS, JavaScript, imagens e mídias

## Novidades da v15
- Área de resultados do ZPack redesenhada com visual mais premium e melhor hierarquia.
- Venas em destaque como participação especial, com o vídeo aparecendo primeiro e foto própria no bloco principal.
- Removida a captura do perfil do TikTok do bloco visual; o link do perfil continua disponível.
- Vídeo e provas do Venas reorganizados em uma composição própria.
- Recomendação em vídeo do Pouca Mira ampliada e reposicionada.
- Imagens e vídeos dos resultados agora possuem visualização ampliada no próprio site.
- Feedbacks de eck100stress, sbr e Z receberam cards mais organizados e com maior destaque para antes/depois.
- Chamada clara informando que os comentários originais e muitos outros feedbacks ficam disponíveis no Discord.
- Link de Resultados adicionado à navegação do ZPack.

## Melhorias da v14 preservadas
- Atalho na Home para resultados reais.
- Ícones SVG monocromáticos nos destaques da v1.0.2.
- Fluxo simples de contratação no ZPack.
- Fluxo de compra/ativação no Limpador Pro.
- Imagens de prova em WebP.
- Vídeos com `preload="none"` para evitar carregamento desnecessário.
- Ajustes responsivos para a área de resultados e fluxos.

## Publicação
Extraia o ZIP e envie os arquivos e pastas preservando esta estrutura. Não envie o ZIP como um único arquivo para o repositório.
